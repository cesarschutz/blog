A caneta do caderno

O marca-texto amarelo e todos os traços estão aprovados. Todas as marcações aqui já vêm feitas, sem animação, como se você tivesse riscado o texto com uma caneta antes de publicar. Cada exemplo aparece nos dois temas lado a lado.

A caneta escolhida é o azul. A caneta nunca pinta o texto: o texto marcado continua na cor normal, e só os riscos e as notas ficam azuis, para não confundir com os links. A barra abaixo ainda deixa comparar com as outras cores.

Cor da caneta:

1. O marca-texto

Quatro jeitos de destacar uma frase inteira, e a opção de não ter marca-texto. O ponto é destacar sem esconder o texto, nos dois temas.

2. Os traços

Os três que você aprovou e mais nove, cada um com um papel. Nenhum post usaria todos: o guia define quando usar cada um.

3. Mais oito, para variar com sentido

Cada um cobre um tipo de destaque que os doze ainda não cobrem. A variedade vem do conteúdo: cada post usa os que o texto pede.

Dica: fique com poucos tipos. Um caderno de verdade costuma ter três ou quatro gestos que se repetem, e é essa repetição que faz o leitor entender o sistema sem explicação.

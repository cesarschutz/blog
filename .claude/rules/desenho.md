# Arquivos de desenho

Antes de criar ou alterar um desenho, leia `docs/estilo-desenho.md` (estilo). Depois, siga a skill
certa:
- `desenho`, para a ilustração do post;
- `lousa`, para os diagramas de explicação.

O que nunca pode:
- cor fixa, `style=`, `stroke-width`, degradê, sombra, `<image>`, fonte de letra de mão, emoji ou
  texto demais;
- `id` ou `<defs>` próprios (filtros e padrões ficam definidos uma vez no layout);
- aceitar o desenho sem passar no validador e sem conferir o render claro e escuro.
